# qa-ai-automation-lab

A hands-on portfolio project where I'm moving from manual QA into test
automation and AI-driven quality engineering. It uses JavaScript and
Playwright to automate UI tests for Sauce Demo and API tests for Restful
Booker, and it will grow to include a Page Object Model framework, CI with
GitHub Actions, AI-assisted test design with documented human verification,
and a small LLM evaluation component. This is a work in progress built over
a 60-day plan; progress is tracked in the commit history.
